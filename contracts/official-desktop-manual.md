# 官方桌面外部验收

这是需要签名官方桌面分发和Windows图形环境的外部验收，不包含在纯SDK自动契约计数中。不得以Web或模拟适配器替代下列桌面行为。

1. 用与UPSTREAM锁一致的原始官方Windows分发，核对官方摘要及有效发布者签名；选择独立EXAMPLE应用数据、DSH home及Agent home，不读取用户会话。
2. 通过官方Electron正常首次初始化并完全退出。公开CLI直接创建`desktop`应拒绝；初始化后的公开`plugin --profile desktop list`应正常完成。不得手工生成或修改桌面私有配置绕过初始化。
3. 通过官方桌面CLI装入确切归档，逐文件核对全部载荷及其自有home归属。测试密钥只经公开凭据服务保存，不写日志或环境。
4. 在真正`dsh-app://app/`窗口创建一轮文件工具对话，不手动改默认模型。观察默认Flash、实际文件工具、文件内未出现在请求中的编号及普通完成状态。记录EXAMPLE截图和脱敏事实，不记录会话全文。
5. 使用应用菜单完全退出，移除自有测试密钥；公开CLI卸载包，核对包不可解析及原公开包列表。完整配置逐行回滚、无密钥表单和15分钟出站抓包必须另有同范围证明。
