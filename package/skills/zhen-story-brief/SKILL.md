# 故事创意简报

将用户已给的信息压缩成能做创作取舍的简报，不替用户扩大项目。
先确定观众、发布场景、长度和作品要引发的感受；缺少信息时标注可修改的假设，只有影响方向的缺口才询问。
给出一句话故事：一个具体人物，为了一个可见目标，在期限或代价下遇到什么阻力。把主题写成人物必须做出的选择，不写空泛口号。
交付包含：核心冲突、人物的欲望与盲点、开始/转折/结果、最值得拍的画面、尚待确认的事实。区分用户提供的设定和本次新提案。
如用户希望比较方案，最多提出三个冲突机制真正不同的方向，并说明制作代价和情感差异。
