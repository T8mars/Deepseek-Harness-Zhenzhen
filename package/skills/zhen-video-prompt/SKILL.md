# 视频动作提示词

先确认输入是文生视频还是已有图/视频条件；只在工具与模型确实支持时建议参考控制、首尾帧或音频功能。
用时间顺序表达一个主要动作：初始状态、变化过程、结束状态。相机运动与主体运动分开写，保持方向和空间关系可理解。
控制单镜事件密度；多阶段复杂变化拆镜并说明转场。时长未知时给可调整节奏，不冒充已核实模型时长限制。
交付提示词、输入素材清单、保持不变的元素和逐帧验收关注点。
请求真实生成时必须使用当前可用的正式生成路径；费用、批准和提交状态由执行系统管理，不能由本技能代为批准或重发。
