# DSH-zhen

非官方社区修改版，与 DeepSeek 无隶属关系。

DSH-zhen uses published packages from DeepSeek Harness under their MIT licenses.
The upstream copyright and license notices remain with those packages. This
bundle does not contain upstream character art, logos or installation artwork.
The public distribution includes only original abstract water graphics and
system-font references. User-supplied artwork requires a separate license record.

Local PDF text extraction uses the external pdfjs-dist 6.4.299 package under
Apache-2.0. Its own distribution retains separate Adobe CMap, PDFium/Foxit and
Liberation font notices. This adapter reads built-in CMap data only; it does not
assign that package's fonts to the user interface. External dependencies keep
their original notices and licenses.
