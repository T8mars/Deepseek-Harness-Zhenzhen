# 从公开 GitHub 仓库安装带资源的技能

技能市场中的“GitHub 技能来源”可以下载单个技能目录或一层技能库，保留
SKILL.md、参考文件、脚本、素材和原许可文件。下载完成后先审阅，明确选择
该快照才会提供给 DSH 的原生技能加载器。安装过程不运行仓库代码，也不安装依赖。

## 连接与调用

1. 填写公开仓库主页地址。分支、标签或提交另填；留空时读取仓库默认分支。
2. 填写相对目录并选择“单个技能”或“一层技能库”。单个技能的目录中应有
   SKILL.md；技能库的各直接子目录中应有 SKILL.md。
3. 下载后查看提交、完整快照摘要、文件清单、技能正文和许可。更新时会显示
   相对当前快照的新增、删除及修改文件，包括正文以外的资源变化。
4. 确认使用这份快照。首次连接可用于后续加载；已有来源换版或回退在下次
   Host 启动生效。切换后新建会话或刷新技能列表。

文本预览最多 128 KiB。较大文件和二进制资源显示大小与摘要，并提供固定到
该提交的 GitHub 原文件链接。许可栏是仓库声明的观察值；`NOASSERTION`
不代表没有许可，实际许可文件按原字节保留。下载不会将第三方材料改为 MIT。

调用保留原来的相对资源目录及手动/模型调用限制。附带脚本是否能运行，仍
取决于 DSH 工具、依赖软件和用户授权；装入技能不会授予工具或付费权限。

## 更新与保留版本

| 操作 | 结果 |
|---|---|
| 每日自动检查并下载候选 | 已确认来源默认开启，可关闭；下载新快照，当前版本保持 |
| 审阅并选择更新或旧版 | 核对完整文件后安排下次 Host 启动切换 |
| 取消待启用版本 | 清除这次选择，保留已下载文件 |
| 停用来源 | 阻止该提供方后续加载，清除待启用选择，保留副本 |
| 移除来源 | 移除连接记录，保留下载副本供审阅或清理 |
| 移除未选中的快照 | 只删除自有缓存中未被当前/待启用版本使用的下载副本 |

自动检查不自动批准资源或程序更新。发布源的纯文字自动更新是另一项
[独立策略](skill-market.md)。断网或下载失败会保留当前选择。首次使用和
启动切换前会核对完整资源摘要，损坏的候选不会替换原版本。

个人改动请放在自己的工作副本，通过[本机技能目录](local-skills.md)连接。
个人目录优先于同名 GitHub 技能，下载和清理不会改写该目录。多个 GitHub
来源同名时按连接顺序选择；项目等其他提供方继续遵守 DSH 原有优先级。
已经进入会话的旧指令无法收回，停用或切换后应新建会话。

## 范围与存储

仅支持公开 github.com 仓库，不使用 GitHub 凭据。Host 读取 GitHub API
并按固定提交下载原文件；核对 Git 树/文件对象和 SHA-256，不运行 clone、
仓库钩子或安装脚本。对象与摘要标识取得的字节，不构成作者签名或代码安全认证。

最多启用 16 个来源。每份快照最多 512 个所选目录文件、32 MiB 所选目录内容，
另保留最多四份仓库根许可文件；单文件最多 8 MiB。Git 元数据条目、路径与
指令解析也有上限。每个来源最多保留 20 份快照；注册快照合计最多 512 MiB、
64 个缓存来源。达到上限需清理未选版本。这个限制不是通用磁盘配额；进程
异常留下的临时目录尚无自动恢复清理。

自有 schema-1 JSON 与快照保存在 DSH_HOME 下的 `dsh-zhen/github-skills/`，
与本机目录记录、纯文字市场 SQLite 分开。符号链接、子模块、Git LFS、私有
仓库和依赖安装尚未支持。普通启动器协调单个 Host；任意多 Host 同时修改的
系统级锁与跨进程清理协调尚未实现，不应共用此数据目录并发维护。
