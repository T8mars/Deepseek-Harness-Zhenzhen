# 用户美术素材

本项目已获用户明确授权使用 imagegen 制作社区角色二创。现有本地素材包
包含首页插图和侧栏/会话头像，原图来源、完整生成提示词和文件摘要随源文件
保留；用户不用再次提供同一素材或重复确认同一二创范围。

本机开发启动器现在会自动使用已确认的
`packages/dsh-zhen-client-brand/assets/community-creative-v1`。
首次打开页面会载入默认首页图及品牌标记；无需重复手动导入。
默认美术位于独立本地文件夹，公开代码包仍不包含实际图片。
默认包在服务启动时固定；替换默认文件后重启开发服务即可更新。个人导入仍即时生效。

在创作空间打开“外观与社区角色素材”，可逐张导入首页图、侧栏标记、
首页小标记及各自的深色替代图。个人替换仅保存在当前浏览器的本机存储，
刷新后仍可显示；浏览器清理数据会删除这份本机副本。原始文件不会改变。

支持静态 PNG、JPEG、WebP。单张上限 2 MiB，宽高各不超过 4096。
动画与 SVG 不在首版导入范围。图片解码失败时显示原创抽象降级图形。
设置页提供四种底色预览、显示模式、焦点与比例选项，以及署名和许可备注。

个人替换和已保存的显示设置优先；缺少个人图片时使用默认包，移除个人
替换会恢复默认显示。可在设置页重新读取默认包、查看作者与许可告知。
若需另选一份已确认的本机默认包，可为启动器设置DSH_ZHEN_ART_ROOT；
可选的DSH_ZHEN_ART_DIGEST用于固定完整内容。配置无效时沿用水纹降级。

```powershell
npm run verify:local-art -- --source C:\EXAMPLE_ONLY\my-art-pack
```

这个验证通过已发布Gateway和客户端分块逻辑核对原始字节，使用全新TEMP，
不修改个人浏览器素材、不调用模型；它不代替实际浏览器的显示验收。

完整美术包是一个包含 manifest.json 和对应图片的文件夹。可参考
`packages/dsh-zhen-client-brand/assets/manifest.example.json`，复制到自己的
美术包目录并填写来源。当前支持 hero-portrait、hero-mark、sidebar-mark
三种槽位，以及 variants.dark 中的同名替代素材。完整导入会原子替换
当前槽位与署名；缺失或无效资产不会导致半套替换。

实际美术文件默认被 Git 忽略，应保留在独立美术包或分仓中。公开代码包
包含原创抽象降级图形，不携带用户导入的图片。

准备一份可审阅的本地分发归档：

```powershell
npm run build
npm run pack:art -- C:\EXAMPLE_ONLY\my-art-pack
```

输出 ZIP 位于 `.runtime/art-packages/`。归档只含清单引用的静态图片和规范化
清单；不会包含旁边的项目文件。分发构建要求 license.confirmedByUser 为 true、
redistribution 为 allowed，并填写确认日期、许可说明及来源。这个字段仅记录
用户确认，不是版权认证。未确认时命令拒绝打包。命令不会上传或发布归档。
可选的 license.notice 字段保存完整来源告知（最多 16000 字符），随规范化
清单进入归档，避免丢失来源版权声明。

接收方解压 ZIP，在外观设置中选择“导入完整美术包文件夹”。本机使用允许
导入许可未确认的清单，仍不代表可以分发。不要把来源链接中的临时签名或
凭据放入公开美术清单。
