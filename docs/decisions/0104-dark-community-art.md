# 0104 · 鲸鱼娘浅深主题素材

原本的本机角色包只有通用插图和头像，深色界面一直复用浅色图。本次使用已获授权的 imagegen 技能，以原图为输入补齐深色首页插图和头像，保留角色、画本、姿态与透明背景，为蓝发和深色服装增加浅青色边缘光。

## 实现

- 形成独立的 community-creative-v2 本机包：原浅色两图逐字复制，新增两张深色PNG，三个槽位均有浅深版本；头像由首页标记和侧栏共享。旧包不修改，生成输出不改像素，来源、原MIT告知、完整提示词与文件摘要单独保留。
- 启动器优先选择已存在的新包，缺少新包清单时支持旧包；用户显式选择与固定摘要仍优先。新包存在但无效时明确不可用，不默默换成旧包。没有本机角色包的公开代码继续使用既有水纹图形。
- 使用既有美术接口与主题槽位，不新增Remote、Agent工具或客户端引导机制。个人替换与关闭角色的选择仍优先。美术原件和生成记录保持独立，不进入代码Git或npm包；可单独导入的本机ZIP只含规范化清单及四张图片。
