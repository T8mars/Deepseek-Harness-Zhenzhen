# 0035 · Windows 源码一键启动与干净声明产物

2026-10-20。为本机源码提供可直接双击的启动和依赖修复入口，仅修改 DSH。
`npm start` 使用同一入口；仍需 Node.js ≥22.19.0 和首次依赖下载，尚非独立安装器。

准备器只依赖 Node 标准库，在任何依赖安装、构建、打包前取得既有端口与
进程租约。依赖、锁文件及 Node/系统身份变化或显式修复时执行
`npm ci --ignore-scripts --no-audit --no-fund`；仅改脚本和文档不会强制重装。
缓存不是全部依赖文件的完整性证明，损坏时由用户选择修复。
构建、干净类型检查及打包成功后，将仍占用端口的真实租约直接交给原启动器。
不改上游 CLI、profile 格式或会话数据；原启动器继续检查 Flash 默认与上报关闭。

准备阶段取消会等待当前命令结束后退出，拒绝下一阶段和 Host 启动。
失败保留个人配置及此前安装记录；这不承诺中断 npm 后依赖目录仍完整，
也不宣称已验证操作系统强制结束整棵进程树的行为。

冷准备发现旧构建遗留五个错误位置的 `.d.ts`，旧开发包曾包含这些非执行文件。
新增清理器先验证整个计划和目录身份，只移除自有生成目录中的过期声明，
拒绝链接或重定向目录；随后强制重建当前声明。打包同时检查源码对应关系与
声明导出完整性，旧声明未清理时拒绝发布且保留产物指针。
新包125文件，较上一130文件包仅移除五个旧声明；执行入口字节不变。
旧标签和本地产物作为历史保留，不重写远端历史。
