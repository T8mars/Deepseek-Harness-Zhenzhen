# 0141 · 恢复状态、社区欢迎页与配对刷新

非空恢复应用保留了技能版本和个人正文，但“已启用”容易与等待来源审阅、管理暂停的状态混淆。卡片与数量现在使用“已选择”，顶部显示恢复管理状态并直达审阅位置。自动偏好继续保留，实际暂停另行说明；读取失败只说状态未确认。正文与历史版本仍可查看，市场写操作等待管理核对，不改变原有授权或后台规则。

连接页重新检测确认兼容时，配对区可能残留旧“未运行”错误。现在每次完成检测都会重读配对，包括同一目录和版本再次检测；旧回复不能覆盖新检查。刷新失败撤下旧的已连接标记。此变化只读状态，不自动发起配对、领取凭据、选择额外权限、应用节点或提交生成。

首次浏览器启动改用社区欢迎页。自有插件通过公开 `settings.onboarding` 列表槽位，只覆盖 `welcome-notice` 单元，保留 Models 编辑器和凭据步骤。说明默认网关、恢复后的审阅、费用确认与非官方关系，保留 MIT 声明。明确点击已读后才经公开配置表单保存；失败留在原页，也可稍后提醒。浏览器原生对话框管理焦点，沿用两套主题与系统字体，不修改上游、词典所有权或引导内核。
