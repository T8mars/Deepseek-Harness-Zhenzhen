# 0108 · 图片任务查询兼容与工作区独立副本

真实图片任务暴露出查询兼容问题：通用 TaskDto 同时包含数字形式的内部记录 ID 和公开 task_id，旧解析器把二者都当作任务编号比较，导致正常任务被拒绝。现在只在通用响应中、公开编号与请求严格一致时接受内部数字 ID；字符串编号冲突、缺失公开编号和其他协议仍拒绝。账户的自定义显示单位也不再被误当成缺失结算。

恢复应用同时补齐工作区独立副本，经固定已发布 Storage/Domain 逻辑复制，配置只指向新副本；保留组件继续用于复核。复制期间不构造 WorkspaceRegistry，不继续历史待处理操作。
