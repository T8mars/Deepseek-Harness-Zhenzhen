报告包含集合相对路径、跳过/失败、固定原因及操作提示，不含正文、绝对根目录、
解析器异常原文或堆栈。每集合最多50条问题、另报省略数量；最多32个集合，
Host退出即消失。按资料空间、集合和当前epoch复核；撤权、更改权限、重新索引或
中断重建后旧报告失效。Owner跨空间请求拒绝；返回副本，调用者不能修改缓存。
导入详情读取失败不把已经完成的索引显示为失败。项目输入在操作期间禁用，
报告还须匹配当前空间/集合/epoch才展示，避免旧报告出现在新集合下。

固定原因区分隐藏/链接、依赖构建目录、不支持格式、2MiB上限、路径或文件变化、
二进制/编码、无正文、密码PDF、解码格式/限制/超时及队列繁忙。沿用原有文件、
页数、子进程和32MiB批次限制，不自动重试。读取解析后不改变源文件；固定读取后
复核路径及设备/inode/大小/纳秒mtime与ctime，变化时不将该次快照加入索引。
这不是跨平台OS沙箱或持续监控承诺；索引仍为授权时读取的本地快照。
没有数据库迁移、检索排序/分词更改、OCR/向量、付费或云解析。
