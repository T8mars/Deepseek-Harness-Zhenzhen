# 0115 · 恢复文件夹技能的正式审阅与撤销

恢复副本此前只提供默认暂停的项目技能来源，生产界面没有放行入口。现在在技能市场与备份恢复页提供同一张审阅卡：当前配置的原启用来源、恢复资源目录和关联项目均可查看，超过20项逐页展示。用户核对范围并勾选确认后才能允许；已允许时可立即暂停。

决定通过既有 Owner Remote 保存，浏览器不传 home、配置档或任意目录。Host 从自己的固定 home、实际 profile、公开 Loader 与完整应用覆盖设置核对来源。只允许当前配置原来已启用的文件系统提供者；全局与项目的原作用范围、优先级、相对资源和停用偏好保持。

审阅决定单独保存到自有 `skill-project-consent.json`，绑定原来源清单的完整摘要与当前配置，不修改原来源清单、SDK 配置或原项目文件。来源变化、坏文件、目录或入口被替换时不能继承批准；SDK 读取前后都核对当前决定。撤销使已有缓存失效，读取中撤销也不能返回该技能正文。正常再次备份保留原启用偏好，生成的新 home 不继承这项批准，仍默认待审。

市场、本地导入和 GitHub 管理来源的暂停及待更新状态仍保持；此批准不授予模型调用、任意文件访问、RAG、MCP、原生画布审批，也不激活整个应用。后续统一权限及启动流程继续，不能将本次文件夹技能放行当作完整 L2 验收。
