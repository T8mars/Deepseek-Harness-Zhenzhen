# 0161 · 等待画布确认时保留同一次请求

真实连接验收中，DSH 已进入等待画布批准，随后因原生发现暂时不可用而显示“未找到运行中的画布”。同一时刻操作系统中的画布进程仍在运行。用户还原并批准后，生产发现恢复为兼容，但旧界面已清掉 pending 状态、停止查询，需要重新检测才能完成。这会让用户误以为必须再次配对。

自有客户端现在只对尚未过期的 pending 请求恢复查询。短暂发现不可用、连接失败、超时或传输中断时，保留原请求，使用递增间隔检查，最多连续四次失败。仍无法核对时只显示“检查这次连接”，继续查询原请求；不重新创建配对、不申请另一份权限，也不提交创作或生成任务。

工具变化、配置变化和其他明确拒绝仍停止恢复；旧 API、旧连接的迟到响应不能开启当前连接。已经配对的状态核验失败仍撤下已连接标记。Native 的精确兼容检查、实际批准范围和凭据存储方式保持。
