# 0083 · 从 Host 收集技能备份来源

2026-10-22。技能备份新增公开 SDK 的 Host 适配器，接入自有服务的
`skillBackupRecords`。这个入口仅供 Host 内总备份编排使用，没有注册为浏览器
Remote，不向客户端发送来源路径、归档口令或原始备份数据。

适配器通过 `Loader.entries()` 遍历已配置的 filesystem 条目，使用公开的
`Entry.fiber.config` 读取活动条目的已验证配置。读取不再次执行原始配置表达式，
不导入、刷新或启用条目，不用技能目录的胜出列表代替完整资源。禁用的普通
配置保留资源根及禁用状态；尚未解析的禁用表达式明确拒绝，不猜路径。公开
builtin 字典识别尚未导入的禁用别名，已导入的模块用公开导出身份识别。

`workspaceRegistry.list()` 的目录、部署默认目录、`workingDirectory.get()`
提供的活动会话目录和总备份传入的额外历史目录按顺序合并。没有读取会话
私有文件或启动 Agent。历史会话中已变更的目录仍需总会话备份提供，当前
适配器不会把活动目录集合声称为完整历史目录集合。

活动条目未就绪、未知文件系统后端、来源超限或必需服务缺失时明确拒绝。
公开 `LocalFileSystem` 可被识别为本机读取；其他后端需要专用适配器。自有
Host 入口只使用已经存在的四个技能服务，不为了备份而构造可能在启动时
激活待更新版本的服务。直接注册的第三方 provider 不属于本适配器的覆盖。

清单中的可选 `enabled` 保持旧归档可读；缺省仍为启用，新增禁用条目的所有
资源根保持禁用。恢复继续创建全新、未启用的候选，完整配置/数据库恢复、
依赖实体、RAG、总恢复预览/激活与界面仍待开发，完整 M2/L2 未完成。

C94 使用真实已发布的 Loader、filesystem provider、本机文件系统和自有

后端零调用、未就绪服务拒绝、目录顺序与超限、错误脱敏、加密往返以及来源
