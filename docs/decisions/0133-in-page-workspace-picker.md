# 0133 · Web 工作目录在页面内选择，知识库显式解除绑定

实际 Windows 回环 Web 页面点击“添加工作区”时，上游自适应插件选择原生目录窗口；网页没有相应弹窗。只读进程检查确认目录窗口由应用 Host 创建，正常刷新网页后该子进程退出。这说明本次操作在等待原生窗口；无法据此认定此前所有点击不响应都由它引起，后续在没有该子进程时仍出现间歇性导航无效。

DSH-zhen 通过 bundle 覆盖禁用 `directory-picker` 自适应行，同时组合已发布 SDK 0.2.1-rc.3 的 browse Host 与 Web 客户端插件。两者作为精确 npm peer 和开发依赖声明。该组合是上游公开支持的接口，目录浏览、路径输入、取消和选择继续交给对应公开组件；不修改上游、客户端引导或 Desktop IPC，也不改画布。

知识库原来在路径为空时把提交按钮改为“解除绑定”，即使尚未绑定也可点击。现在空路径的绑定按钮禁用，空表单提交不发出请求；已有绑定单独显示明确的解除按钮，清空草稿不撤权。解除请求保持原先的重复操作、连接与空间变化保护；迟到响应不会覆盖新连接状态，操作期间编辑的新路径草稿会保留。
