2026-10-20。为补齐文件服务器实际修复验收，先发现并复现了一个DSH侧缺口：

连接。停用后重新启用时，旧会话的直接/已准备工具调用仍可到达服务器。

允许型pre-policy也不能放行修正后的调用。

同时核对持久会话代次；旧代次返回新建会话提示。模型请求前的检查保留。
普通重启不换授权代次，仍可继续同一会话。不修改上游、会话格式、SQLite
schema或已保留授权，不增加新的审批步骤。
