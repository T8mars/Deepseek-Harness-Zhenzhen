# 0049 · 画布模型选择与音频方案

2026-10-20，开发检查点。媒体执行继续复用画布的RunIntent/报价/窗口审批链路。
本轮不增加DSH直连付费提交台账，也不修改上游或画布仓库、安装版与CLI目录。

DSH连接页增加音频/音乐方案、按所选项目/画布读取的模型目录，以及明确的
文本/图片/视频/音频模型选择。Story可分别选择四类模型；留空沿用画布推荐。
图片/视频可调1–8候选，另可选择策略、比例及视频/Story时长；具体可用规格
由原生模型决策校验。音频、剧本和Story的界面保持单候选，未扩大其候选语义。

新增owner Remote `canvasWorkflowModels`，仅访问原生公开`/models`；只投影
模型身份、可执行及凭据就绪布尔值，不回传设置、原生参数或阻断说明。每次
明确选择在预览前重新读取原生状态，返回后复核同一CLI/配对。不存在或未就绪
模型不发送规划POST。原生`requiresRuntimeCheck=true`可与`executable=true`
并存，前者不单独作为阻断项；仍要求已知、安装、凭据、线路、可用与可执行
全为true，且没有阻断项。nullable/旧目录未知状态可展示，不能作为可执行选择。

原生计划必须逐项保留请求的provider/model、候选数和显式比例/时长/策略，
不一致时不落入可审批记录；界面显示实际计划参数。选择已失效时保留其可见
名称和待核对状态，不把下拉框悄悄显示成自动推荐。原会话/审批持久化格式与
10个只读MCP工具不变；新增DTO输出为可选字段，旧预览记录仍可读取。
