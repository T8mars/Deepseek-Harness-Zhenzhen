# 0146 · 聊天和技能使用同一个画布连接入口

0144简化了实际连接页，但系统提示、内置画布技能和聊天帮助卡仍提示“重新检测、选择推荐画布”。用户从聊天进入时可能再次走入技术设置。本次统一为：打开桌面画布，点击“连接画布，开始创作”，在画布确认一次后自动完成。默认申请七项能力，旧部分授权如实显示并使用同一入口升级；不要求填写目录、实例或手动完成。

内置`zhen-canvas-handoff`升为1.0.7，正常生成技能目录及公开指令索引，便于既有技能更新机制发现变化。未连接状态和工具移动的提示也指向同一按钮。既有帮助记录协议、Owner调用、原生兼容和实际授权范围不变，不扩大Agent工具权限。
