# 0118 · 技能管理拒绝时给出明确下一步

恢复技能管理尚未启用或已暂停时，点击市场更新、本地连接或 GitHub 下载，原先可能得到普通异常、目录无效或网络限频提示。现在实际 Owner 服务在原写入检查前核对管理授权，并将两类确切拒绝转换为已发布 SDK 的 `RemoteError('zhen/refused')`：未启用/暂停时指向「恢复后的技能管理」启用操作；配置或来源变化时指向「检查管理状态」。诊断原因保留在结构化 `reason`，主提示使用中文，不显示内部编号。

市场、目录和 GitHub 使用相同的拒绝含义。原网络、目录格式和来源错误继续沿原处理路径，不统一改成权限错误。原管理类仍执行自身检查；没有自动启用、重试、下载或变更待更新。只读预览、停止下载、SDK 指令读取及普通未恢复应用保持原行为。
