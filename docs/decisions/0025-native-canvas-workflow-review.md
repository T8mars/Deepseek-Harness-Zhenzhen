# 0025 · 连接页创作方案与原生窗口应用

2026-10-20。状态：已实现，隔离协议回归通过；真实画布窗口与新界面待验。

连接页现在可读取原生工作区、选择目标画布，为图片、视频、剧本或 Story
输入目标并创建一个省钱候选。调用现有 creative-plans，不创建第二套规划器。
预览展示目标 revision、候选/变更数量、模型、问题和计划引用。用户核对并明确
确认后，才向原生 creative-approvals 请求窗口审批；画布窗口批准后，再显式
检查并完成原生 creative.apply。只写入可编辑工作流，不启动任何模型。

默认配对权限不变。可单独勾选 canvas:write，须重新配对且由画布窗口授予；
没有增加 run:execute。Agent 的十个检查/规划工具不变，没有新增批准或应用工具。
这是连接页的人工应用流程，尚不能自动接收聊天中生成的计划。

复用原生实例发现、完整摘要握手、会话验证、审批服务、secureStore 与 Patch
应用端点。轮询秘密只进原生 secureStore；自有 schema 1 文件仅保存非秘密
引用、创作目标、简化预览和进度，供重开页面后复核；不保存完整方案、令牌或轮询秘密。
实例、地址、CLI 摘要、配对身份、项目、画布、计划摘要、operation/patch 和
结果 revision 均要核对。连接变化、原生记录替换、未准备好或过期时拒绝。
审批卡展示原生计划绑定的创作目标；它必须与本次输入相同。修改表单后必须
重新预览，不能把仍然有效的旧计划误认为新输入。

两个 POST 前先保存 requesting/applying；丢包、保存失败或重启中断会显示
结果不明，不再提供该项重发。原生明确拒绝过期/失效计划可重新预览；窗口
pending 只等待，denied 不修改画布。已知完成结果先保存，再尽力精确删除本次
原生审批记录。自有进度不宣称多 Host 文件事务、物理断电或远端恢复保证。
