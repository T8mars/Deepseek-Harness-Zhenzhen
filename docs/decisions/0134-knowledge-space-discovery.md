# 0134 · 直接选择已有资料空间，区分空结果与授权问题

真实界面验收发现，用户必须记住资料空间名称并手动填写，才能找到已导入的集合。现在知识库直接列出已有空间，仍可手填新名称；选择只改变当前表单范围，不绑定目录、不修改集合、不授予模型权限。列表每页最多50个名称，提供前后分页和刷新；读取失败保留草稿并允许显式刷新，没有自动重试。绑定但尚无集合、以及含撤回集合的空间仍能找到。

此能力放在自有Host、Owner远程方法和客户端组件中，不修改上游。Host只查询本地索引元数据，不扫描资料目录、不返回路径或正文、不读凭据。名称按数据库二进制顺序做游标分页，跨连接的迟到响应失效；重复翻页仅受理一次，收到列表不会自动选择空间。

已授权集合的多个关键词采用全部匹配，真实会话曾先得到空结果，缩短成实体名称后才命中。空结果说明和工具参数现在优先建议缩短关键词、分开检索；仍无结果再检查索引、绑定与授权，不再将空结果当成未授权。检索算法、授权边界、来源卡片和旧记录格式不变。
