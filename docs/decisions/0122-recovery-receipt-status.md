# 0122 · 检查状态解除等待与空缓存测试安装

“打开恢复应用”的回执丢失后，界面会保留等待状态，避免重复打开。但即使随后手动检查已确认原窗口关闭，旧等待标记仍未清除，重新打开按钮也一直不可用。生产组件事件测试已实际复现这组互相矛盾的提示。

现在当前候选的 Host 状态确认已有打开记录时，统一更新状态并清除本次等待和旧提示。未确认的状态继续只查询，不自动重发。明确重新打开仍需用户点击，并使用新的请求编号；后台原有请求去重、执行标识、授权与未知状态保护不变。

产品变更是客户端状态同步修复；另修正实际进程测试的依赖安装夹具，没有新增 SDK 接口、后端协议、画布调用或权限。连接、候选与组件生命周期的原 guard 仍保留。
