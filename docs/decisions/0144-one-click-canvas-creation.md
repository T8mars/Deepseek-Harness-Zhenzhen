# 0144 · 一键连接画布，默认申请完整创作能力

用户实际连接时，DSH只申请三个读取权限；创作开关藏在折叠区域，批准后还要返回手动完成。用户于2026-10-26明确要求使用方便、默认完整能力、无需手动选择工具或匹配版本。本次将正常入口收敛为“连接画布，开始创作”。

一次明确点击会自动寻找正在运行的桌面画布及配套工具，核对指纹和原生兼容性，再申请全部七项既有能力：画布读取、任务读取、素材读取、素材交接、浏览器移交、修改画布、执行生成。版本与目录处理放在后台；路径、实例与手动检测收进高级设置。画布重启后只有一个就绪实例时自动更新实例选择；确有多个窗口时要求选择目标，不随机连接。

已有完整会话直接继续使用；已有只读会话可通过同一按钮申请完整能力。重复点击合并为一个请求。桌面批准结果每两秒自动检查，成功后自动完成连接；拒绝、过期、失联或页面卸载后停止。不会因为只得到部分能力就声称全部开启，也不会自动再申请。保留原始CLI secureStore和原生会话绑定，未新增配对状态格式。此处的“全部能力”属于连接范围，实际应用和生成仍使用既有原生审批流程。
