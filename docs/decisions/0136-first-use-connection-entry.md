# 0136 · 无密钥时，在会话顶部直接连接 Seedance

独立 EXAMPLE 配置通过正式 dev105 归档和公开 CLI 首次启动后，默认会话只显示“请选择模型”，没有说明应到哪里添加令牌。进入创作空间后，“连接 Seedance”能正常打开自有设置，但这个额外发现步骤不符合新手直接使用的要求。

现在在已发布 SDK 的 `conversation.header.leading` 槽位提供直接入口：状态尚未返回时显示“连接与设置”，明确未配置时显示“连接 Seedance”，读取失败时显示“检查 Seedance 连接”。点击只定位既有自有设置页，不自动保存凭据、查询钱包、测试模型或授予任何权限。确认已有凭据时不显示此入口。切换连接后旧回执失效，离开页面后不更新状态，不自动重试。

该槽位在 rc.3 的公开类型中为 root / single，公开扩展目录记载默认无占用，适用于没有会话的页面。C208同时核对该契约与自有注册，不覆盖上游文件、默认会话模型、用户预设或导航行为。独立按钮为浅深两套明确颜色和焦点样式，无装饰动效。
