# 0057 · 可替换的本地检索后端

2026-10-21。M3要求后端可换。原本地资料工具直接依赖KnowledgeStore，不能通过
扩展替换召回策略。本轮在自有插件中提供ctx.zhenRag与Host后端注册表，默认仍为
原有中文词法检索，不增加云端或向量依赖，不改变索引schema、排名或集合授权。

后端只得到问题、已授权的空间及集合修订号、取消信号和可选的词法候选函数；另提供按需读取的授权索引分页，用于本地后端构建索引。
最终
只允许返回至多12个片段ID/epoch。正文、路径、引用及会话授权由本地索引重新
解析。外部后端可以召回词法候选以外的合法片段，不是仅重新排列词法前12条。
未授权/过期/重复/附带伪造正文的编号整体拒绝，不产生部分新会话授权。

SQLite事务内验证。缺少绑定或集合授权时不调用后端。注册是受信任Host代码扩展，
不是模型工具、远端下载安装或网络/CPU沙箱；同步扩展不能被异步超时强行抢占。

知识库新增明确状态及暂停/恢复。其他后端仅在已经安装的扩展注册后出现，选择
放在高级区域。暂停不删除索引或取消集合授权；含已有自动检索引用的会话在LLM
发送前也被拦截，恢复可继续。设置仅保存后端ID和开关，显式保存并原子替换；
用当前修订拒绝跨窗口旧设置。损坏或缺少所选扩展时显示修复入口，不静默降级。

取消、超时、切换/卸载和配置变化均拒绝在途旧结果。新结构化错误沿已发布
HarnessError/ToolRuntime的error.info.code传递，客户端按固定代码显示操作提示，
不展示扩展抛出的原始错误详情。查询完成后、工具再次检查上下文期间暂停的真实
异步交错先在契约中复现为成功结果，补齐最终修订检查后转为RAG_PAUSED。
