# 0149 · 官方桌面十五分钟进程网络观察

使用原始签名rc.3桌面分发和39ce归档，在独立EXAMPLE配置进行真实默认Flash帮助工具对话、连接页和本地资料页浏览。借助固定版本Microsoft TraceEvent的Windows实时网络事件，按新建桌面进程的实际父子关系筛选，其他应用事件在写入前丢弃；只保存时间、进程、目标地址/端口和DNS结果，不保存请求正文、凭据、命令行或原始ETL。

## 已验证

实际捕获900045毫秒，2671条网络事件、128条DNS事件，事件丢失、解析错误及截断均为0。全部落盘事件可归入实际桌面进程树；唯一自有随机命名追踪会话已停止。短控制实验另验证自建子进程被记录、外部进程被排除，以及HTTPS目标与DNS答案对应。

外部连接仅观察到`api.seedance.nz`及`harness.deepseek.com`的443端口。后者来自原始官方Electron主进程；分发内公开代码和清单提供匿名`/api/v0/check_client_update`更新策略，支持将其归因为官方更新检查。未改写官方更新协调器或将所有DeepSeek地址加入许可名单。网络事件只证明本次目标和时间范围，不证明加密HTTP载荷内容。

实际帮助对话正常完成，默认Flash、1轮2步，未执行Shell或生成作品；帮助卡被折叠的问题据此修复于0148。十五分钟捕获本身正常退出0，但总观察助手随后等待菜单退出超时，真实退出1，不能将整次桌面助手报告为成功。后续核实自有桌面进程为0，测试凭据经公开API移除、公开CLI卸载及原空包列表恢复均通过；原用户凭据和安装未修改。

## 待验证

完整桌面配置逐行卸载还原、无密钥桌面表单流程以及自有发行版的完整出站范围仍需分别验收。当前结果不替代正式分发检查，也不将M0整体标记完成。
