# 0148 · 画布入口在会话顶部直接可见

0146的实际官方桌面验收暴露了入口问题：默认Flash正常调用帮助工具并完成回答，但“打开画布连接”按钮随工具记录折叠，用户只能看见让自己寻找按钮的文字。不能让新用户先展开“已完成”再寻找连接卡。

使用已发布的`conversation.header.leading`公开槽位，在会话顶部常驻“画布创作”。点击直接打开既有画布连接页，不执行检测、配对、授权或生成。该入口不依赖模型回答、工具卡展开或已有密钥；原有Seedance首启入口继续按其状态显示。复用已验证的浅深主题按钮样式，未修改上游导航或画布。

系统提示、帮助卡和内置画布技能统一优先指向这个可见入口；技能升至1.0.8。连接页仍只有一个主要连接按钮，默认申请七项能力，并在画布批准后自动完成。
