# 0111 · 恢复项目的继续会话入口

固定 SDK 的工作区成员按不可变会话头中的创建目录核对。仅追加工作目录变更事件，不能让恢复会话进入另一个目录的工作区。本次增加可选的“为新目录建立继续会话入口”：用户在恢复项目页选择现有目录并勾选后，输入原备份密码，生成新的独立候选。

原备份组件、原应用会话副本和原工作区副本完整保留。继续副本通过公开 Session、Persistence、Storage 和 Domain API 生成：新会话使用新编号和所选目录，以原会话为父级，继承原历史及切分位置；新工作区副本关联这些编号。附件、标题、排序、置顶、归档和历史待处理记录保持。子 Agent 的来源与层级保留，不提升为普通会话入口。没有构造工作区注册器或运行 Agent，旧任务和旧授权不会因此恢复执行。

选项默认关闭；未选择工作区时不提供该选项。旧请求省略新字段，原备份 schema 与旧候选读取器保持。界面在连接、候选、备份来源或禁用状态变化后拒绝旧回调；勾选与目录输入使用当前值，避免下一次渲染前提交旧选择。Host 仍只接受已认证 Owner 请求，并在主机解析项目中的会话编号。
