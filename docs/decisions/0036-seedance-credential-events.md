仅改 DSH 插件，不改上游或画布。

此前只有本插件的保存/移除按钮会使检查、任务查询和媒体导出失效；原生
`credentials/reference-updated` 事件只处理 GitHub 入口。现在同一公开事件
也处理 Seedance 引用，并复用统一失效方法。本页保存/移除仍在写入前主动失效，
兼容不发送该事件的凭据提供方；真实提供方写入后再次通知也安全。
其他凭据引用变化不影响 Seedance。

钱包增加本次读取的代次与取消信号，在凭据解析前后及响应返回后检查。
换号、移除或服务退出会停止旧读取；即使运输层迟到返回旧账户余额也拒绝发布，
不重试、不把余额当成新账户余额。页面保存新令牌时清空此前显示的余额。
这不是浏览器跨标签同步协议，其他标签已经显示的旧值仍需刷新。
