# 0117 · 恢复技能的日常管理与完整备份

恢复应用此前只能逐项批准技能调用，安装、个人修改和更新始终暂停。现在市场与备份页提供「恢复后的技能管理」：核对完整来源范围后启用独立技能库，当场切换提供者，无需填写路径或手动重启来启用管理。可以暂停、重新启用；更新授权损坏时提供明确的重新审阅操作，保留技能数据。

同一恢复应用的配置共用一份独立管理数据，包含全部保留版本、个人副本、停用项、来源、待更新记录和原始偏好。调用、管理及自动检查授权按配置分别确认。尚未整体启用的配置仍可逐项批准调用，不能因此修改技能或继承其他配置的自动授权。原恢复组件和来源文件保持不变；再次恢复到新 home 时不继承授权。

旧 pending 和原自动偏好不是新的更新批准。手动选择或 GitHub 批准生成当前配置的确切版本收据；自动更新还要求当前配置重新开启并实际校验固定来源。收据只允许正常启动应用一次对应的待更新，不进入备份。共享 pending 只有一个最新批准者。暂停立即阻止写入和在途下载发布，当前技能继续可读；重新启用只清本配置更新授权，原数据保留。

目录文件变化只刷新已校验的候选与提供者目录，不重新构造管理器、应用 pending 或发起网络请求。界面说明技能修改会同步到其他配置。普通未恢复应用保持原管理方式；文件夹技能、模型、知识库、原生画布及整个应用启用分别处理。
