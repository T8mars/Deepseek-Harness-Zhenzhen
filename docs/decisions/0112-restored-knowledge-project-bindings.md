# 0112 · 恢复项目时同步知识库目录关联

恢复会话可以选择新目录，但此前知识库的目录绑定仍指向原位置，创作会话因而找不到对应资料空间。本次将经过 Host 核对的原目录与新目录关联传入知识库装配，只修改新候选的逻辑副本。资料空间标识、集合编号、检索引用和资料原件保持。

知识库空间标识与文件系统路径是两项数据，不把空间改名成新路径。显式选择的绑定获得新的单调递增修订编号；未选空间保留原绑定。所有绑定在新空库的同一事务中装配，支持两套空间互换目录，并在创建副本前拒绝占用冲突。原目录已经不可用时仍可从已校验组件完成恢复，不读取原项目内容。

会话应用回执记录 SDK 读出的原始目录，组合流程使用这份已验证回执。浏览器仍只发送项目选择，不输入会话编号或知识库 SQL。目标目录的实际身份在装配前后复核；取消、替换、缺失、冲突及修订容量限制均保留明确错误，不切换原数据。

集合原有恢复规则保持：新授权 epoch、关闭模型访问、暂停检索后端；历史授权完整保留并继续失效，不移交给继续会话。普通会话目录关联和可选的继续入口均支持这项知识库关联。
