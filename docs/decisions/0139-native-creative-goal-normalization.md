# 0139 · 中文创作目标与画布文本规范化兼容

桌面画布已由用户完成配对，DSH 能读取能力、工作区和活动画布，但含中文全角标点的图片方案仍被拒绝。实际返回的项目、画布、类型、动作和有效期都匹配，只有创作目标不同：画布将全角冒号、逗号转换为半角。该行为与画布 v3.4.0 的 `agentControlCreative.js` 中 `text()` / `creativeBrief()` 一致：NFKC、移除 NUL、去除首尾空白。规范化后的目标也用于原生节点提示词。

DSH 保留原始请求，仅允许返回目标精确等于原始目标或按上述规则算出的目标；不规范化返回文本以扩大匹配，也不放宽项目、画布、动作、类型、有效期、模型、输出和素材校验。返回文本有变化时，自己的方案记录保存 `requestedGoal`，界面同时提供输入原文与原生实际方案目标，并提示核对字符变化。重新打开方案仍能对照；审批保持未勾选。没有修改原生画布或上游文件。
