# 0097 · 让已有备份组件进入可操作的备份恢复页面

此前多个备份组件仅有 Host 库入口，用户无法在创作空间操作。本次增加「备份恢复」导航、明确范围选择、密码确认、文件夹选择、备份文件列表和原任务进度。恢复生成独立候选目录，页面明确候选未激活。完整应用恢复、身份与路径统一回绑仍未完成。

## 实现与边界

- 六个范围复用已有实现：配置与插件、会话附件、完整技能库存、本地知识库、自有生成记录和已打开的工作区域。不可用来源不作空数据；不为备份初始化技能市场或冷工作区域。
- 总归档完整认证；内层组件仍以加密文件暂存。所有来源先准备，租约保留到总归档末尾再次检查；错误、取消或来源变化不发布不完整文件。恢复先检查外层完整结构和每份内层认证，再创建全新的候选目录；后续任一组件失败会清理整个候选。
- 环境备份增加可保留的租约。Host 明确选择枚举全部 profile 的四类依赖字段；原单项库调用保持原有显式 seed 语义。来源与恢复仅用固定已发布 SDK 的公开接口。
- Host 技能来源补充全部公开持久化会话 header.cwd，并在技能流前后及总归档末尾检查该会话库存，避免历史目录变化后仍发布旧范围。
- 六个严格 Owner Remote 仅提供状态和明确的本机操作，没有新增 Agent 工具。单项任务不重复启动；回执丢失后只按原编号查状态。密码不写入任务、清单或设置，提交时清空页面密码框；原始异常不进入任务结果。
- 当前入口的作品范围是索引与记录，不复制作品原件。MCP 程序/数据/维护档案、DSH 自有画布进度/审批/回执、更新偏好与角色引用仍不覆盖。凭据不含；旧权限、画布申请和付费任务均不执行。
