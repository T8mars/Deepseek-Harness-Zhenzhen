# 画布Agent交接：新用户只确认一次连接

用户要求：使用方便，默认全部创作能力，不让新用户查找设置、匹配版本、填写CLI路径、复制验证码或逐项开启权限。

DSH已经自动寻找运行中的桌面画布及其配套连接工具，在后台完成既有兼容检查，单次申请canvas:read、run:read、asset:read、asset:transfer、browser:handoff、canvas:write、run:execute七项既有能力，批准后自动完成连接。旧的三项读取连接使用同一按钮升级，不需要新协议。新的连接页面继续收起手动工作流及MCP工具，完整授权后可直接返回会话。

请核对画布端当前实现，并仅补缺失部分：

1. 正常DSH请求显示全部七项能力，默认选择完整创作范围，不让用户去其他设置补开。
2. 桌面画布只显示一次普通确认，主按钮“允许 DSH-zhen 连接”；把独立的“已核对验证码”勾选与批准合并。验证码和兼容摘要归入详情，不要求复制输入。
3. 请求到达后让确认窗口可见；多窗口、过期或拒绝给清楚的下一步，避免静默无响应或反复弹窗。
4. 保持既有请求身份、来源、nonce、有效期、实例绑定和实际批准范围。减少授权时回报实际范围，DSH不显示为完整开启。

验收路径：打开桌面画布 → DSH点“连接画布，开始创作” → 画布确认一次 → DSH自动显示可创作。刷新和单实例重启无需重新找工具；多个画布时按名称选择。

本DSH Agent未修改画布仓库、安装、配置或CLI。本文不授权画布生产构建、版本升级、推送、tag或Release；实际生成继续沿用既有审批和单次提交语义。
