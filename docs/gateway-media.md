# 将任务结果保存到本机

任务中心中，成功任务可点击“获取结果清单”，再逐项或依次批量保存。填写
一个已存在的本机文件夹，文件由 Host 下载并写入该目录。浏览器收到的是
短期结果编号、来源主机和本地保存记录，不接收签名媒体链接或 API 令牌。

Windows 可粘贴“复制为路径”产生的带引号路径；只接受普通盘符下的现有目录，
不接受 UNC 共享地址或设备命名空间路径。原生文件夹选择器尚未接入。

清单五分钟内有效。过期后重新获取原任务的结果清单；不会重新生成，也不
调用收费提交接口。链接也可能由服务提前失效，此时只能重新查询原任务。
任务状态查询仍遵守原来的间隔与退避，刚重启或刚检查后可能需要稍后刷新。

## 保存和记录

文件名由本项目生成，不采用服务返回的文件名、提示词或标题。下载完成后
按字节特征识别媒体或归档格式，计算 SHA-256，再以不覆盖方式复制到选定
目录，并重读核对字节数和摘要。记录保留本机路径、格式、大小、摘要和保存
时间，不保留来源完整链接、签名、提示词、歌词、内容副本或凭据。

当前识别 PNG、JPEG、WebP、GIF、AVIF、MP4、M4A、WebM、Matroska、WAV、
MP3、AAC、Ogg、FLAC、GLB 和 ZIP。单文件最多 2 GiB；不转换媒体、不解压
归档、不执行程序。HTML、JavaScript、SVG 和未识别格式不会作为成功媒体保存。
格式识别不是完整解码或媒体质量验证。

重复点击同一清单项会共享当前操作，已完成后返回已有保存记录；更换保存
目录应重新获取清单。已有同名文件不会被覆盖。文件复制使用
[Node 的 COPYFILE_EXCL](https://nodejs.org/download/release/v22.19.0/docs/api/fs.html)，
它不保证原子复制，应用只在完整核对后记录成功。进程在复制时退出可能留下
未记录文件，请核对目录；不要将没有保存记录的文件视为已验收资产。

若文件已完整保存而记录写入失败，本页仍显示路径并提示复制保存，重试同一
清单项不会再次下载。此时记录仅在本页保留，关闭页面后不能保证恢复。
“最近保存记录”最多显示 100 条，存储最多 500 条；可移除记录释放名额，
导出的文件始终保留。移除任务追踪也不会删除这些文件。

## 连接与停止

媒体请求不发送 API Authorization、Cookie 或 Referer。每次连接及跳转都会
检查目标和全部 DNS 答案，拒绝本机、私网与保留地址，并将选定地址直接用于
连接。跳转最多三次，使用独立连接和默认 TLS 校验；媒体传输不走浏览器。

“停止当前下载”不会取消生成。下载阶段会中断并清理本次临时文件；本机复制
已经开始时可能完成，已经保存的文件保留。通过本项目连接页替换凭据、移除
相应任务或关闭 Host，也会使未开始的保存能力失效并停止进行中的网络下载。

自有 `dsh-zhen/media-exports/receipts.sqlite` 为 schema 1。结果地址只在 Host
内存中短期保留，不进入该数据库或任务数据库。正常退出清理本次临时目录；
异常退出可能留下 staging，当前尚无自动恢复/清理入口，十个遗留目录会阻止
继续下载。目录身份检查不构成对恶意同权限进程的操作系统沙箱。

| 已验证 | 待验证 | 未验证 |
|---|---|---|
| 全量 173 项检查；十二项单测覆盖公网地址、DNS 混合/重绑定、跳转、限额、文件类型、取消、目录漂移、不覆盖及存储失败 | 新界面、实际 CDN/TLS、大文件和更多真实结果类型 | 自动恢复遗留临时目录、原生目录选择器、媒体质量 |
| C23 用实际发布的 Host/Remote 与隔离 HTTP 媒体流保存合成 PNG，核对原字节/摘要、重启历史、撤销和零媒体凭据 | 实际画布资产导入与任务关联 | 没有真实网关媒体、收费生成或画布写入 |

## 送到画布

保存记录的“送到画布”只传已有记录编号。在连接页独立申请素材交接权限并由画布批准后，可读取目标画布、核对文件并请求窗口确认导入。放到画布另需修改画布权限和第二次预览/确认。原文件保留；已有相同内容会复用素材。结果不明只查询，不重发。当前限额由画布声明，常见默认 512 MiB；ZIP 等画布不支持的类型会拒绝。移除保存记录撤销尚未开始的本机文件交接，不删除已导入的原生素材。详见[0030](decisions/0030-saved-media-canvas-transfer.md)。
