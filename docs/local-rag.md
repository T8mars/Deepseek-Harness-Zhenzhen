# 本地资料检索

知识库读取用户授权文件夹中的 UTF-8 Markdown、TXT、CSV、JSON、DOCX正文和带文字层的 PDF。
单文件最多 2 MiB，一次导入原文件与提取文字分别最多 32 MiB。索引保存在本机，
导入不上传全文；图片、扫描件 OCR、向量和语义问答尚未实现。

PDF 在本机独立进程解析，每份最多 200 页、提取文字 2 MiB、30 秒。无文字
PDF 跳过；密码保护、损坏或超限计失败。各页独立分块，出处显示真实页码及
该页提取文本的位置；复杂排版、字体编码可能影响顺序和识别，不是视觉还原。
原文件不修改，导入不自动授予云端引用或 Agent 检索权限。

导入后可在集合中查看“上次导入详情”，也可点击“查看导入详情”。报告列出相对
文件名、跳过/失败原因和处理提示，最多50条，剩余问题只显示数量。它只保留在当前
运行内存中，最多32个集合；重启、重新索引或权限变化后旧报告不再可用。失败的
详情读取不影响已完成的索引。它不包含正文或解析器报错原文，也不会自动进入会话。
编码错误可先另存UTF-8；超大资料请拆分；密码PDF需无密码副本，扫描PDF需文字层。

DOCX读取正文段落和表格，可见内容按文档顺序提取；引用使用提取正文行，不是Word页码。
不还原页眉页脚、脚注、文本框、自动编号或图片，旧版DOC、加密/含宏主文档类型、
外部主文档及altChunk暂不支持。原文件2MiB、ZIP最多512项、主XML8MiB、提取文字2MiB，
固定本机子进程限时30秒。无正文跳过，损坏或超限计失败；导入不改变资料引用授权。

检索使用关键词。输入“洛川 琵琶”会查找同时含有这两个关键词的片段；
可调换顺序。中文支持单字和相邻双字，拉丁词不区分大小写，全半角经过
统一处理。也可直接输入常见中文问题，例如“如何用角色的动机推动场景转折？”。
交集检索没有结果时，可识别的中文问句会尝试分词并按部分词语匹配；这不是
语义理解，片段可能只覆盖部分问题，请核对出处。没有中文分词支持的运行环境
保留原关键词行为。专名较长或问句没有命中时，仍可改用较短的关键词。
引号、OR、星号等不作为可执行的 FTS 查询表达式。

问句分词会尝试还原被拆开的连续汉字词，例如“三幕”“情节点”。只有当前
可访问的索引片段确实含有该连续词时才合并，每词最多四字；空白、标点和
停用词阻断合并。词汇查询同样过滤资料空间、集合和当前模型/Agent权限，
每问最多32次并缓存。未知词仍保留原分词，不能推断同义词或理解语义。
这是查询端修正，已有索引无需重建；关键词AND和原文出处保持不变。

最多返回 12 个片段。排序先取各文件中得分最好的一个，再取各文件的
第二个，以此类推；同一轮仍按词法相关性排序。这样，一份很长的参考
不会用重叠片段占满全部位置。代价是同一文件的第二个高分片段可能排在
另一个文件的首个片段之后。不同集合重复导入的文件仍是独立文档；本版
没有跨集合内容去重。文本出处继续使用相对路径和原文起始行号；PDF 另外标注页码及提取文本行号，DOCX标注正文提取行。

资料空间和集合权限在排序前过滤。手动复制引用与允许会话检索是两项
独立授权；后者还需要精确绑定实际工作目录。撤权、重建索引或更换目录
会使旧引用失效。已有检索内容的会话会在下次模型请求前重新检查授权，
不能靠重建索引来恢复旧会话权限。自有 SQLite schema 由 2 事务迁移到 3，
旧片段 page 默认为 0；保留原记录、授权和绑定，不修改已安装的 DSH 会话。
旧版程序拒绝打开 schema3；回退代码时不能删库，须先保留原索引备份。

可以运行 `npm run build` 后执行 `node scripts/evaluate-rag.mjs`，在系统
临时目录创建、评估并删除一组完全虚构的 12 文件资料。21 个关键词用例
覆盖中文短名、单字、中英文混合、全半角、跨分块内容、出处和无匹配。
在同一合成数据库的“琵琶”用例中，旧 SQL 的前 12 条只有一份长文，
修改后包括全部 5 份相关文件；文档召回率由 1/5 变为 5/5。这不是面向
真实创作资料的通用质量分数。中文问句的词法候选同样不表示系统理解问题。

评估证据保存在忽略的 `.runtime/evidence/rag-quality.json`。C11 另通过
真实已发布的 DSH ToolRuntime 验证授权过滤、多个文件返回、原文出处与
撤权；该项资料及模型均为合成/隔离环境，没有真实云端请求。

## 查看来源与上下文

知识库检索结果可点“查看来源上下文”，在本地查看当前索引中的原文片段。
每次至多三个相邻片段，可继续向前或向后翻页；相邻片段有重叠，也可能从
某行中间开始，界面明确显示“第几行附近”。这是索引快照，不会重新打开源
文件，不代表文件的实时内容，也不会自动发送给模型。查看来源与允许云端
引用、允许会话检索仍是三项不同的操作。

对话中的 `zhen_rag_search` 结果显示来源卡片，包含集合、相对路径、起始行
和可展开的原文。需要更多上下文时，助手可调用 `zhen_rag_open`，用检索返回
的编号与版本读取来源；继续翻页沿用返回的相邻编号。它不接受文件路径，
不能读取任意文件。必须先在同一会话检索过该集合，且当前目录绑定、集合
版本、Seedance授权及会话检索权限仍全部有效。另一个会话不能借用引用。

卡片来自原生工具输出的可重放metadata；失败或最终策略阻止的结果不展示
成功卡片。旧记录没有metadata时仍可展开原始工具记录，不改写会话文件。
撤权、重建索引或换绑定会阻止后续读取与模型请求；已经存在的历史记录
不会因此从原生会话中消失。Schema仍为2，没有数据库迁移或额外授权。
