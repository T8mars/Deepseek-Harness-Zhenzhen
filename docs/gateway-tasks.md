# 查询生成任务状态与实扣费用

创作首页的“任务”入口可以记住已有任务编号，查询状态、进度和终态实扣，
也可在 Host 后台持续追踪。它只查询已有任务；媒体创作的执行与审批仍走画布。

## 使用方式

1. 在“模型与钱包”保存 Seedance 令牌。令牌只由 Host 凭据服务读取。
2. 打开任务中心，按原提交接口选择协议，粘贴任务编号并点击“添加并查询”。
   不要粘贴 API 令牌或媒体链接。
3. 需要持续查看时，点击“自动追踪此任务”。这项选择会保留，Host 重启后
   会继续查询原编号；到达终态后自动暂停。
4. 终态尚无实扣金额时，可稍后手动刷新。移除本地记录不删除上游任务。

| 任务类型 | 固定查询路径 |
|---|---|
| OpenAI Video 风格视频 | GET /v1/videos/{id} |
| 旧版通用视频任务 | GET /v1/video/generations/{id} |
| 图片 | GET /v1/image/generations/{id} |
| 异步音频 | GET /v1/audio/generations/{id} |
| 混元 3D | GET /v1/3d/generations/{id} |
| Suno / Flow Music | GET /v1/music/tasks/{id} |
| Midjourney | GET /v1/midjourney/tasks/{id} |
| MiniMax H3 V2 | GET /v2/query/video_generation/{id} |

协议根据[网关公开文档](https://api.seedance.nz/docs/llms.txt)分别解析，不能互换。
返回记录的编号必须与查询编号一致。进度到 100% 不等于成功；未知的新状态
会显示“待确认”并暂停自动追踪，不猜测为完成。

## 费用和结果

只在终态并返回合法 `usage.amount` 与 `usage.currency` 时显示最终实扣。
运行中的 usage、旧版 cost、credits_cost、quota 和预扣都不替代最终实扣。
没有 usage 时显示“尚未返回”，失败也不自行推算为零。服务明确返回零金额
时会保留并显示零；不进行汇率换算。

当前任务中心保留媒体链接数量，不保存或返回签名链接、生成正文、提示词、
标题、歌词、服务端失败原文或完整响应。成功任务可获取短期结果清单，
[将媒体保存到本机](gateway-media.md)；回到画布的资产关联尚未接通。

## 追踪控制

图片任务最小查询间隔为两秒，其余协议为五秒。Host 每五秒选择一个到期任务，单个 Host 同时
只发起一次查询；同一条记录的同时刷新共享该次请求。手动刷新遵守已经记录
的间隔与退避，可能返回最近状态而不立刻再次出站。成功但仍在生成的响应和限流响应均遵守 Retry-After；秒数及HTTP日期均可读取，最多等待一天，重启后仍保留该期限。
网络中断和服务故障会退避，保留上次观察，不因此认定生成失败。

鉴权失败、令牌缺失或协议格式变化会暂停自动追踪。通过本项目连接页更换
或移除令牌会中断在途查询、暂停追踪，并丢弃旧连接代次的晚到响应。通过
其他 DSH 设置更换凭据时，后续操作按公开凭据接口重新解析，不宣称能够
取消外部设置变化前已经发出的请求。

“暂停追踪”只停止本机后续轮询。MiniMax V2 另有删除/尝试取消协议，本任务
中心不会调用它，也不会将它套用到其他模型。此处没有提交、重发、删除上游
记录、取消生成、任意 HTTP 或自动重试创建入口。

自有 `dsh-zhen/gateway-tasks.sqlite` 使用 schema 1，最多记住 100 条记录。
移除只影响本地记录；在途查询完成后也不会把已移除记录重新插入。已开启
追踪的任务允许 Host 后台只读查询，不自动向 Agent 会话注入结果。
