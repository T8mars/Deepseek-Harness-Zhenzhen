# DSH-zhen

> **状态：开发中（2026-10-20）。** 已有可运行的 DSH Web 扩展、创作首页、Seedance 凭据/钱包、本地文本知识库与会话检索、15 项技能市场与远端候选下载、画布检查/规划 MCP、聊天方案交接、连接页人工方案与窗口审批应用及更新检查。真实网关兼容、完整创作对接、远端发布和签名安装激活尚未完成。逐项实现与未验收范围见 [当前交付状态](docs/delivery-status.md)。
> DSH-zhen 是 DeepSeek Harness（DSH）的非官方社区修改版：默认走 Seedance 网关的 `deepseek/deepseek-v4.1-flash`，「潮汐」主题 + 鲸鱼娘角色槽位，内置创作 SKILL 与 RAG，后续经专用 MCP 对接 T8-penguin-canvas。

## 本地开发运行

需要 Node.js 22.19.0 或以上。依赖版本已锁定；不使用浮动 DSH `latest`。

Windows下载或克隆源码后，可直接双击根目录 `start-dsh-zhen.cmd`。首次运行
会按锁文件准备依赖、构建并检查扩展包，再通过官方CLI启动认证浏览器；后续
依赖未变时复用安装。依赖损坏时可双击 `repair-dsh-zhen.cmd`，重新准备依赖，
保留 `.runtime/dsh-home` 中的配置与资料。旧服务仍运行时会在准备前退出，
请先在原DSH窗口停止服务；此入口不会强制结束现有进程。

这是源码版的一键启动入口，仍需本机Node.js与首次依赖下载，不是独立安装器。
命令行可直接运行 `npm start`，或用 `npm start -- --no-open` 禁止打开浏览器。
仅检查准备与配置、不启动服务可用 `npm start -- --check`。

```powershell
npm start
```

开发检查可在依赖准备后运行 `npm run check`；源码打包可用 `npm run pack:bundle`。

启动器通过 DSH 官方 CLI 创建独立配置并安装本项目扩展；测试数据位于忽略的 `.runtime/`。服务只监听 `127.0.0.1:5180`，默认打开认证浏览器。进入侧栏“创作空间”使用功能。已手动构建/打包的开发者也可用 `npm run start:prepared -- --no-open` 跳过源码准备。

可另运行 `npm run smoke:install`：通过官方 CLI 在一次性临时配置中安装当前已打包产物，核对组合配置并检查 Host 的回环监听，随后关闭并清理。该检查不使用浏览器或付费接口，也不替换现有开发配置。

另有 `npm run verify:canvas-native -- --canvas-root "D:\Example\T8-penguin-canvas"`：在可信的画布源码开发树和Electron依赖上验证原生业务路由、临时数据库及聊天交接；不读取用户历史库，不执行付费生成，窗口确认由测试模拟。使用与限制见[画布连接说明](docs/canvas-mcp.md)。

添加 `--include-run-intent` 可额外验证原生运行计划、双门审批和丢回执GET恢复：只在新建TEMP写一条原生运行意图，不启动Provider调度。真实窗口与付费生成仍待验证。

再添加 `--include-asset-transfer` 可在同一隔离验证中检查真实原生素材导入与放置。画布接入所需的38文件源码补丁与逐项恢复校验见[修复交付说明](integrations/canvas/README.md)；当前安装版3.3.6的兼容清单与发现故障已有工作源码修复，尚未生产发布。

画布侧改动现交由用户的画布Agent处理，DSH仅负责本项目适配。待审核范围、复现与接口合同见[画布Agent交接](docs/handoffs/canvas-agent.md)；当前暂缓画布发版。

根目录私有工作文件不进入 Git、npm 包或发布产物；提交/推送钩子与 CI 检查提供误操作防护。验证后的代码更新将提交并推送到本仓库，以开发版本标签保留可恢复检查点；这不表示已发布稳定安装版。验证范围与限制见 [实施决策](docs/decisions/0001-published-runtime-foundation.md)、[上游契约](docs/upstream-assumptions.md) 和 `features.json`。

技能市场提供正文预览、安装、停用、保留版本与个人副本，并可每天从指定仓库下载固定提交的候选正文。可选择信任该来源的纯文字更新，自动为已启用技能安排下次启动更新，也可固定某个技能或跳过某版；默认仍逐版审阅。已打开会话的 `/` 列表由上游缓存，安装后可新建会话或使用刷新入口。详见 [技能更新说明](docs/skill-market.md)。

仓库当前按用户要求保持私有，后续由用户决定公开。更新中心提供可选 GitHub 只读凭据，仅用于本仓库的技能目录与版本检查；公开后可继续匿名读取。本入口不推送代码，不会将凭据交给模型或其他技能仓库。

默认模型已通过本机模拟网关的流式、工具往返、取消及错误契约。真实 API 仍待受控验证，范围见 [聊天兼容报告](docs/seedance-compat.md)。依赖审计的剩余上游问题见 [审计记录](docs/dependency-audit.md)。

模型与设置页提供 [网关能力目录](docs/seedance-capabilities.md)：18 款对话模型配置文字路由，默认仍为指定的 Flash；媒体与动作保留独立协议和适配状态。公开来源每日检查产生差异，不直接开放新付费工具。

知识库只索引授权的文本目录。多个关键词用空格分开，优先展示不同文件，最多返回 12 个片段。自动会话检索需要额外绑定实际工作目录并逐集合允许，默认关闭。检索引用的权限改变后，旧会话会在下次模型请求前被阻断，应新建会话继续。详见[本地资料检索](docs/local-rag.md)。

检索结果可查看并分页浏览本地来源上下文；对话中的资料卡片保留集合、相对路径和起始行。助手可继续读取同一会话已授权来源，不能用引用编号跨会话或读取任意文件。显示的是索引快照，查看本地来源不会自动授予云端发送权限。

“模型与钱包”另有 Flash 连接检查：先预览固定短消息，再明确确认可能产生的用量费用，最多请求 32 个输出 tokens。检查只提交一次，中断不自动重发，历史记录不保存模型回答。它只验证一次基础文字流，详见[连接兼容说明](docs/seedance-compat.md)。

首页的[任务中心](docs/gateway-tasks.md)可按已有编号查询八种媒体任务协议，显示状态、进度和终态实扣。手动开启后可在 Host 后台持续追踪并在重启后续查；暂停和移除只影响本机记录，不重发或取消上游任务。

成功任务还可[逐项或批量保存媒体结果](docs/gateway-media.md)到指定本机文件夹，保留摘要和路径记录。保存后可选择送到画布，分别核对导入与放置并由画布窗口批准；需要具备新版素材控制面的画布。下载不携带 API 令牌，不覆盖已有文件；结果地址只在 Host 内存中短期使用。

画布连接页支持“检测本机画布”，选择工具后核对摘要并信任连接，也可手填 `zcanvas-cli` 目录。首次配对可直接从页面发起，在画布窗口核对批准后返回完成，凭据仍由原生工具保存。它提供 10 个读取与规划入口；[画布连接说明](docs/canvas-mcp.md) 介绍现有 39 项高层能力的 73 个 L0 规划/预览操作及八个检查工具。更新中心每天读取版本信息；[上游候选工作流](docs/upstream-updates.md) 会准备精确依赖、审阅指南与配置差异并隔离验证，另由独立任务创建 PR。工作流已推送，但GitHub因账号付款/支出额度未启动作业，远端自动验证尚未完成。启动器会在服务仍运行时拒绝安装新版扩展，请先停止 Host。

MCP 市场另提供项目记忆与项目文件两个固定来源。下载校验后，信任具体程序版本并绑定项目才能使用；已启用来源可自动下载兼容更新候选，审阅后在下次 Host 启动切换。现可重启连接、重新下载并保留旧程序副本、核对后还原；替换后需重新信任，项目记忆保留。程序以本机用户权限运行，详见 [MCP 使用说明](docs/mcp-market.md)。

技能市场还可[连接本机技能目录](docs/local-skills.md)：预览并信任单个 SKILL.md 或整库，保留相对参考资料、脚本和素材；本机修改用于后续加载。连接不执行脚本或安装依赖，停用/断开保留原文件。

也可[从公开 GitHub 仓库下载技能](docs/github-skills.md)，按提交保留完整资源并审阅文件差异。每日检查只下载候选，审阅换版在下次 Host 启动生效；保留版本可回退或清理，个人工作副本优先且不会被覆盖。

“外观与社区角色素材”支持本机图片/完整美术包导入、浅深替代图、显示模式和四底色预览。已按用户授权制作社区角色二创的首页图与头像；开发启动器自动载入本机已确认的独立默认包，个人替换与关闭设置优先。公开代码包保留原创抽象降级图形。素材装配见 [美术包指南](docs/art-packs.md)。

## UI 设计稿

标题"DSH-zhen 界面设计稿"，在 Claude 的设计画布里共 12 个画板：新会话 Hero · 对话 · 输入框与 `/` 技能选择器 · 技能库 · 知识库 · 画布联动面板 · 模型与网关 · 首次引导 · 外观与角色美术设置 · 插件市场 zhen 频道 · 角色美术槽位 · 潮汐令牌。链接：https://claude.ai/artifact/2fTm3dWx2EKzLWsQ6YGqzC （私有，仅你本人可打开；要给别人看需在页面的分享菜单里授权）。

`design-source/*.dc.html` 是画板源文件，**需要设计画布的运行时才能渲染**（引用的 `support.js` 不在本包里），当作数据与标记的参考即可。设计稿中所有金额、模型档位、项目名、插件名均为示例；角色位全部是虚线占位框，**没有绘制鲸鱼娘**。

## 关于 `reference/` 里的路径与脚本

三份完整备忘录是在规划沙箱里写成的，里面的 `/tmp/claude-0/…` 路径（上游浅克隆 `upstream/dsh`、`upstream/canvas`、Seedance 文档副本）**只存在于那个沙箱**，不在你的机器上。要复核时，请重新克隆：

- `https://github.com/deepseek-ai/deepseek-harness`（基线标签 `dsh-v0.2.1-rc.2`，提交 `687f282e`）
- `https://github.com/T8mars/T8-penguin-canvas`（基线 package 3.3.6）
- Seedance 文档：`https://api.seedance.nz/docs/llms.txt`

备忘录里的行号是上述基线上的快照，会随上游更新漂移；`scripts/gen_css.py` 里的输出路径也需要改成你自己的。
