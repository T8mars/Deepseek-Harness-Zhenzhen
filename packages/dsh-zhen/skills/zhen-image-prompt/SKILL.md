# 图像提示词工作台

拆分不可变约束与可探索元素，先确定主体行为、空间关系、构图、光线和视觉材质，再补细节。
参考图角色、产品和标志只按用户提供内容锁定；不要在提示词里添加互相矛盾的镜头和光线。
给出可直接复制的主提示词，必要时附精简负面约束与参数建议。模型未知时用普通自然语言，不伪造模型专用参数。
若要做多张，保持共同规则，逐张改变明确的变量以便比较。
提示词本身不代表生成已执行。记录需检查的文字、手部、结构和参考一致性。
