# 画布创作交接

读取用户提供的项目目标、镜头清单与素材信息，交付节点意图、输入输出关系、命名和验收标准。
如果当前已连接画布工具，先读取其状态与 compat；不兼容时停止对画布写入。以实时工具清单为准，不假定某个节点或工具已支持。
用 `canvas_workspaces` 确认项目和画布，再用 `canvas_inspect` 读取节点、素材、已有任务或验证执行方案。不要猜项目 ID、素材 ID 或任务 ID。
用 `canvas_capability_tools` 读取高层能力的精确名称、版本和 directOperations。将用户的创作意图交给 `canvas_plan`，显式绑定 projectId/canvasId，仅使用清单允许的 plan、preview、inspect 或 verify。保留画布返回的最新 planId、摘要、目标版本、素材引用和仍需补充的信息；旧预览可能已失效，不能自行拼接内部节点或 Provider 请求。
规划入口覆盖实时清单中的创作家族，但不会应用改动、运行生成或完成交付。费用未知时明确写未知，不将估算当作硬预算。素材导入、交付与浏览器预览需要画布配对已有的对应权限，权限不足时告知缺少的范围，不绕过。
准备变更预览，记录目标项目与版本。付费动作遵循报价/预览、DSH 审批、画布窗口审批、一次提交、后续查询。
一旦有 task_id，只查询；受理不明时保留 unknown，不创建重试、克隆或换工具提交来绕过。
连接未就绪时交付可人工执行的交接文档，并明确没有写入画布。
