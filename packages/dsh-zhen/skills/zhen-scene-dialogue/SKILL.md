# 人物与对白

明确场景中每个人希望对方做什么，以及为什么此刻不能直说。用说话策略、停顿与行动表现关系，不靠一长段解释背景。
每个角色选择不同的句长、信息习惯和回避方式；差异服务于人物，不靠标签化口音。
保留用户指定的情节点。改写时让至少一个说话策略因对方反应而改变，场景结尾应改变一项关系、信息或行动承诺。
交付可拍摄场景，必要时附简短“修改了什么及其作用”。动作只写能看到或听到的内容。
不把虚构对白当成真人原话；涉及引用时明确区分。
