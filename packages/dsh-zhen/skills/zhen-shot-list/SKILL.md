# 分镜与镜头清单

以叙事动作切镜，不按每句话机械分镜。先找每段最需要观众看到的变化，再决定景别与机位。
每镜列出：镜号、预估时长、主体与动作、景别/角度、镜头移动、可见环境、声音、前后镜连接、素材需求。
写清动作起点和终点；运动方向、视线、道具位置应连续。一个镜头只保留可在其时间里完成的动作。
说明哪些镜头可用现有素材，哪些需要拍摄或生成。生成建议仅交付创作计划；实际工具是否存在和生成授权另行核实。
最后检查总时长、重复画面和缺失的因果镜头。
