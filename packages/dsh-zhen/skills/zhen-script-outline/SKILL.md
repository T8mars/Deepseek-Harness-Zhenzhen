# 口播脚本结构

按观众已经知道什么、需要理解什么组织段落。开头用具体矛盾或问题建立观看理由，避免无证据的夸张承诺。
每段只推进一个判断，给出支持它的事实、示例或可见动作；标清仍待核实的主张。用户提供的原文中有关键限定时保留。
把口播与画面建议分栏，画面必须解释或证明这段话，不只重复字幕。用前一段留下的问题引出下一段。
交付可朗读的连续正文、段落作用与预计时长。时长根据实际字数与用户语速估算，说明假设，不把估算当精确音频时码。
用户已有稿件时先保留其语气和事实，再做结构修订。
