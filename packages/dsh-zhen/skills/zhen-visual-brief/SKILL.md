# 视觉方向板

先描述参考中可观察的构图、色彩比例、光线、材质和画面节奏，不臆测品牌或作者意图。
选择少量可执行的规则：主/辅色用途、焦点位置、主体尺度、光源方向、背景复杂度、文字留白。说明规则如何支持情绪和信息层级。
交付一个主方向和必要的对照方向，附适用镜头、容易失控的元素及验收点。
对用户指定角色只使用其已提供的素材信息；不补造被禁止的角色外形。素材许可未知时记录为待确认，不把网络可见当可分发。
本技能交付文字简报；生成或编辑图片需用户任务实际要求与可用工具。
